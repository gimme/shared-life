# Shared Life

Makes all players share one health/hunger bar. When one player takes damage or eats food, it affects all players in the world. The intention is to create a challenging multiplayer experience where players cooperate to survive (or blame each other for their deaths). Ideally paired with hardcore mode.

### Features
- Shared health bar.
- Shared hunger bar (optional).
- Shared experience (disabled by default).
- Announcement in chat when someone takes damage (including amount and source).

**Note:** After a server restart, the first player to join will use their current health/hunger to initialize the shared values.
